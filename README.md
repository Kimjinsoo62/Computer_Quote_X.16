# ⚡ 컴퓨존 견적 자동화 & Apple Store 견적 시스템 Ver XI.02

컴퓨존(Compuzone) 조립PC 및 Apple Store 공식몰의 실시간 견적을 자동 수집하고, 단가 조절 · 부가세 계산 · 중고 시세 검색 · 네트워크 다중 접속 · 작업내역서 작성 · 8종 Excel 견적서 발행을 지원하는 올인원 업무 솔루션입니다.

## 🆕 Ver XI.02 주요 변경

1. **🔴 [닫기] 버튼 강화** — 모든 팝업의 [✕ 닫기]를 흰색에서 선명한 빨간색으로 바꾸고, 작업내역서 도구줄(인쇄 버튼 옆) · 계산기 창 · 사용설명서 탭에도 [✕ 닫기]를 달았습니다. 인쇄 후 앱 창(브라우저)의 ✕로 프로그램 화면 전체를 닫는 실수를 막기 위해서입니다.
2. **📋 작업내역서 비용 · 서명** — 비용 칸에 입력하는 대로 천 단위 콤마가 붙고(`formatTrCostInput`), 칸 폭을 천만 원 단위(99,999,999)까지 넓혔습니다. 서명 캔버스의 내부 크기(280×90)가 화면 크기(전체 폭×48px)와 달라 칸 위쪽 절반에만 그려지던 문제를, 그리기 시작할 때 캔버스 크기를 화면 크기(× devicePixelRatio)에 맞춰 고쳤습니다.
3. **📦 GitHub ZIP 설치 오류 수정** — `install.bat`의 `if errorlevel 1 ( … )` 블록 안 `echo … (app 폴더 위치 확인)`의 이스케이프 안 된 `)`가 블록을 일찍 닫아, 설치가 성공해도 `pause` → `exit /b 1`이 실행됐습니다. 그래서 `.venv`가 없는 새 설치(ZIP)에서 `START.bat`이 "install.bat failed"로 멈췄습니다(`^(…^)`로 수정). 함께: ZIP 을 풀지 않고 실행하면 압축 해제를 안내, pip 업그레이드 실패(긴 경로의 WinError 206 등)는 경고만 하고 계속, `.git`이 없는 ZIP 설치본에서 [업데이트] · `update.bat`은 pull 대신 안내 메시지(`update_service.ZIP_INSTALL_MESSAGE`).
4. **📌 작업내역서 도구줄 고정** — 내역서를 스크롤해도 [새로 작성 · 저장하기 · 인쇄 / PDF · Excel · ✕ 닫기] 도구줄이 위에 고정됩니다(`position: sticky`).

## Ver X.42 주요 변경

1. **⚡ 엑셀 견적서 미리보기 속도 개선** — 썸네일 8장 20초 이상 → 첫 장 약 1.6초 · 8장 약 3.5초, 크게 보기 · 다운로드 3~10초 → 약 0.1초(8코어 PC 기준).
   - **상주 Excel 워커**(`app/pdf_export.py`): 앱 시작 때 숨은 Excel 을 최대 3개 띄워 폼1~8 샘플로 예열하고, 서식별로 나눠 동시에 PDF 로 바꿉니다. 15분 안 쓰면 닫히고, 앱 종료 · 서버 비정상 종료 때도 스스로 닫힙니다. 비상용 PID 는 `.excel_worker.pid` 에 적어 `stop.bat` · `force_stop.bat` 이 그 PID 만 정리합니다(사용자 Excel 은 건드리지 않음).
   - **빠른 프린터**: 워커 Excel 안에서만 활성 프린터를 `Microsoft XPS Document Writer` 로 바꿉니다. 네트워크 복합기가 기본 프린터면 PDF 내보내기가 2~4배 느려지기 때문이며, Windows 기본 프린터는 바꾸지 않습니다.
   - **썸네일 따로 받기**: 화면이 폼1~8 을 `forms=N&thumb=1` 로 동시에 요청해 다 된 칸부터 채우고, 몇 장째 · 경과 시간을 보여 줍니다. 같은 서식의 PDF · 썸네일은 10분 캐시하고 동시 요청은 한 번만 만듭니다.
   - **수집 결과 재사용**: 화면 목록 API 가 수집한 견적을 Excel · PDF · 메일 요청이 10분간 그대로 씁니다(`main._shared_fetch`). 요청마다 하던 컴퓨존 재수집(약 3초)이 없어지고 카드와 견적서 금액이 같아집니다.
2. 앱을 쓰는 동안 숨은 Excel 이 메모리를 약 450MB(3개) 사용합니다. 코어가 적은 PC 는 1~2개만 띄웁니다.

## Ver X.41 주요 변경

Excel 이 없으면 샘플 그림으로 대신합니다.

## 🚀 빠른 시작 가이드

### 1. 프로그램 실행
- GitHub 에서 ZIP 으로 받았다면 먼저 **압축을 풀고**(경로가 짧은 곳 권장, 예: `C:\`) 풀린 폴더에서 `install.bat` → `START.bat` 순서로 실행합니다. Python 3.10 이상이 필요합니다. ZIP 설치본은 `.git`이 없어 [업데이트] 버튼 대신 새 ZIP 으로 다시 설치합니다(`git clone` 설치는 [업데이트] 가능).
- `START.bat` 을 더블클릭합니다. 처음 실행하는 PC라면 필요한 패키지를 자동으로 설치(`install.bat`)한 뒤 시작합니다.
- 백엔드 서버(FastAPI/Uvicorn, 포트 `8090`)가 구동되며, 주소창 없는 깔끔한 독립 브라우저 창(App 모드)이 자동 실행됩니다.
- 같은 네트워크의 다른 기기에서는 `http://[서버PC_IP]:8090/` 으로 접속할 수 있습니다.

### 2. 프로그램 종료
- 화면 우측 상단의 **✕ 종료** 버튼을 누르면 서버 프로세스 종료, 8090 포트 반환, 임시 캐시 정리, 앱 창 닫기가 일괄 수행됩니다.
- 비정상 종료 시 `stop.bat` 또는 `force_stop.bat` 을 실행하세요.

## 📋 주요 기능 안내

### 1. 컴퓨존 조립PC 견적
- **AI PC 견적**: AI 데스크탑 기획전 상품 라인업 실시간 수집.
- **프리미엄PC / 아이웍스PC / 추천조립PC**: 실시간 BOM 부품 슬롯 및 최신 판매가 수집.
- **🎮 게임으로 PC 찾기**: 게임(최대 4개)과 모니터 해상도(FHD/QHD/4K)를 선택하여 최적 PC 추천.
- **💵 금액대로 찾기**: 예산 범위(만원 단위)를 입력하여 전 카테고리 실시간 검색.

### 2. Apple Store 견적 및 CTO
- MacBook, iMac, Mac mini, Mac Studio, iPad & iPhone, Studio Display 등 공식몰 판매 제품 실시간 수집.
- **⚙️ 사양 CTO 수정**: CPU/GPU 코어, RAM 용량, SSD 용량, Nano-texture 글래스, AppleCare+ 보증 연장 등을 실시간 추가 및 총액 자동 계산.
- **정품 단가 그대로 적용**: 올림이나 반올림 로직 없이 애플 공식 홈페이지의 실제 판매가(원단위) 그대로 화면 및 Excel 견적서에 정확히 반영.

### 3. 견적 옵션 및 마진 제어
- **옵션 토글**: 모니터, 무선키보드마우스, 메모리 32GB(AI PC), 초기 세팅비(0원이면 별도청구).
- **💳 마진 원클릭 순환**: `C(30% 소비자견적)` → `25%` → `20%` → `15%` → `10%` → `0%(원가)` 순으로 순환 변경.
- **단가 비례 분배**: 마진율 변경 시 모든 부품의 단가에 동일하게 비례 분배되어 단가 총합과 견적 합계가 일치.
- **💰 단가표시 / 단가미표시**: 고객에게 개별 부품 단가를 감추고 합계금액만 제안하고 싶을 때 원클릭 전환.

### 4. Excel 견적서 발행 (전문 서식 8종)
- **전체 다운로드**: 상단 `📥 전체 비교 Excel` (모든 견적을 견적요약 비교표와 함께 1개 파일로 일괄 저장. 최종 견적서 1건은 카드별 버튼 사용).
- **단일 다운로드**: 카드별 `📥 엑셀 견적서` (해당 제품 1건만 저장).
- **8종 디자인 시트**:
  - `견적요약` (비교 제안 마스터표)
  - `폼1 (표준)` (B2B 표준 견적서, 공급자/수급자 직인란)
  - `폼2 (인보이스)` (영문 모던 INVOICE 스타일)
  - `폼3 (보고서)` (결재/보고용 총액 강조 요약형)
  - `폼4 (명세서)` (부품 엔지니어링 기술 명세서형)
  - `폼5 (리테일)` (매장 즉시 발송용 영수증 스타일)
  - `폼6 (조립PC)` (부품별 A/S 기간 및 4대 소비자 유의사항 명시)
  - `폼7 (데스크탑)` (제품 상세 SPEC 표 및 고객 발주확인란 구비)
  - `폼8 (클래식)` (관공서/기업 납품 세로형 등록번호 전통 서식)
- 모든 시트는 **A4 세로 1페이지 폭 맞춤(Fit to Page)** 및 여백 15mm가 사전 세팅되어 인쇄 시 잘림 방지.

### 5. 컴퓨터 작업내역서 (출장/수리)
- 고객 정보, 장비 사양, 접수 증상 및 점검 소견 작성.
- 작업/부품 비용 입력 시 공급가액, 부가세, 청구합계 자동 연산.
- 현장 전자 서명 패드 내장.
- **A4 1페이지 규격 종이 인쇄 / PDF 출력**, 서버 DB 저장 및 이력 관리, Excel 다운로드 지원.

### 6. 독립 팝업 계산기
- 상단 `🧮 계산기` 클릭 시 브라우저 밖으로 띄울 수 있는 독립 팝업 창 제공.
- **부가세 역계산** (합계금액에서 공급가액과 부가세 분리) 및 **부가세 더하기** 지원.
- 계산된 금액 행 클릭 시 계산기로 금액 즉시 복사.

## 🛠️ 기술 스택 및 구조

- **Backend**: Python 3.12+ / FastAPI / Uvicorn (포트 `8090`)
- **Frontend**: HTML5, Vanilla CSS3 / JavaScript (No external framework dependencies)
- **Scraper**: urllib / BeautifulSoup4 (컴퓨존 실시간 상품 페이지 & Apple 공식 스토어 라이브 동기화)

- **Network**: `0.0.0.0` 바인딩을 통한 로컬 및 LAN IP 다중 클라이언트 지원
